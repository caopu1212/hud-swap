# HudSwap：游戏 HUD 换位覆盖层

把屏幕上的几块 HUD 区域实时交换位置（可旋转 90°/180°），盖在原处显示。

最初是给《明日方舟：终末地》手柄模式做的：在游戏外把手柄的 A/B、X/Y 对调后，右下角技能盘的图标方位和实际按键对不上，用它把技能盘的「左↔上、下↔右」换过来。

**不修改游戏文件，也不读写游戏进程**：只截屏（GDI BitBlt，和录屏软件同类），再用置顶的透明窗口画上去。

## 特点
- **多状态自动切换**：每个状态（如技能盘普通 / 按住 RB 激活）记一块识别图案（白色字或标志），每帧比对，自动选用对应的那套交换；都对不上时（菜单、过场）自动隐藏
- **识别不怕半透明背景**：只比较「白色笔画比紧挨着它的一圈亮多少」，UI 后面透出来的画面怎么变都不影响
- **预判切换**：当前状态的标志一帧内消失（按下或松开 RB 的瞬间），立刻切到另一个状态，不等新状态的淡入动画
- **低延迟**：跟随屏幕刷新率（实测 100 帧/秒），覆盖层比原画面晚约 1～2 帧
- 覆盖窗口：逐像素 alpha，胶囊 / 椭圆 / 矩形形状加边缘羽化；鼠标穿透，不抢焦点，不会被截屏捕获（不会把自己截进去）
- F8 开关；可设置只在游戏窗口位于前台时显示

## 使用
1. 游戏设为**无边框窗口或窗口化**（独占全屏下覆盖层显示不出来）
2. `启动.bat`（需要 Python 3 + numpy + Pillow），或用 `打包.bat` 打包成 `HudSwap.exe`
3. 「新建状态」→ 倒计时内切回游戏，摆好要截的状态 → 在截图上：
   - 先框一小块**只在这个状态出现的白色字或标志**作为识别图案（如 RB、字母 Y），框得越贴越准
   - 再成对框选要交换的区域：先拖出 A，再在 B 的中心单击（自动生成同尺寸的框），或直接拖出 B
   - 按 R 切换旋转方向（会根据两块的位置自动推算），右键撤销，回车完成
4. 主界面会实时显示每个状态的匹配度

配置和识别图案保存在程序同目录（`hud_config.json`、`tmpl_*.png`）。

## 诊断
勾选「记录诊断」后，程序会逐帧把各状态的匹配度写入 `hud_debug.csv`，并把每次切换后 0.5 秒的画面存到 `hud_debug_frames/`，用来调整阈值。
